# Exercise F — exported Android component (omitted)

This optional exercise is not implemented. A custom exported activity, receiver, service, or provider would add native code and verification work that could delay the core mobile pentesting demonstrations.

Inspect the merged manifest for the components generated by the React Native CLI. The launcher activity is exported so Android can launch the application; that fact alone does not establish a vulnerability. Risk depends on what external callers can make the component do, required permissions, input validation, and authorization.

A future extension should expose only a harmless synthetic action, require appropriate access controls, and demonstrate both an authorized and unauthorized caller. Validate it from a second test app or controlled adb intent, and document the exact component contract before adding it to the live talk.
